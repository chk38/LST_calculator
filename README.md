Land Surface Calculation  is a significant remote sensing workflow. 
But it consists of 5 separate time-consuming steps, that require you to fill in the formulas each time. 
That's why upon learning python geospatial libraries, I developed my first project: a python script that automates the task of LST calculation. 
Just copy and paste the code in the Python window in your ArcGIS software. And hit enter.
Tested and verified the code in both ArcMap 10.8 and ArcGIS Pro. 
*Requirements*
Make sure Arcpy library is installed in your computer.
Edit and customize your raster file locations for B4, B5 and B10.
